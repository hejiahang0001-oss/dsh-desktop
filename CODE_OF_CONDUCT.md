# Code of conduct

DSH Desktop contributors and community members are expected to make participation respectful, constructive, and welcoming.

## Expected behavior

- Discuss ideas and code without attacking people.
- Assume good intent while asking for evidence and reproducible steps.
- Respect privacy; remove credentials, personal paths, private repository content, and session text from reports.
- Accept maintainer decisions about project scope, security boundaries, and release readiness.
- Give credit for ideas, testing, documentation, and code.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, deliberate disruption, publishing another person's sensitive information, or knowingly submitting malicious code are not tolerated.

Maintainers may edit or remove content, close interactions, or restrict participation when necessary to protect the project and its community. Serious concerns should be raised through the repository's private vulnerability-reporting route when security or privacy is involved.

This policy is informed by the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

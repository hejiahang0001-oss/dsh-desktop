# DSH Desktop V1.1.13 — Latest 候选

本版正在验证，尚未覆盖安装或公开发布。Stable V1.1.12 及其原安装包不变。

## 本版范围

- 固定官方 Harness `dsh-v0.1.6-alpha.1`，提交 `0a15e36e7f82b6ed45af6fa9759f29b40dcd965d`。285 个 DSH 发布包及 9 个 Cordis 家族包使用固定来源；继续应用经过审计的八项精确安全依赖补丁，不改上游业务源码。
- 接入官方侧栏多终端、归档恢复、附件菜单/预览和 MCP resources；对话、Queue/Steer/Stop、文件预览继续由官方实现负责。
- `Ctrl+Alt+T` 和命令面板打开官方终端。`Ctrl+Alt+K` 打开明确标注的兼容终端：助手仅能在你逐次授权后读取其有界、脱敏输出，不会读取官方终端或抢占其键盘控制。官方缺少独立只读接口，因此兼容终端本版暂不删除。
- 修复自动代码检查点将终端等文本框误识别为聊天框、截走回车的问题；识别和发送按钮均限定在同一官方聊天卡内。
- 桌面配置显式关闭 `session-log-deepseek.enabled`，普通模型请求不额外附带完整的原始会话日志；用户主动提交给模型的消息和工具结果仍按正常模型调用发送。
- 保留软件优先的加密 Key、代理设置、Git Review/检查点、Office 校验/备份回执、Wiki、独立工作树后台任务和 Windows 生命周期保护。

## 验证状态与边界

固定运行库构建与摘要、本地物理依赖审计、608 项完整测试及审查后 26 项复验通过。官方终端、归档恢复、旧会话冷读、软件加密 Key 下真实 Excel/Word 附件读取已验证。整包、排队/插话、覆盖安装及公开下载仍待收口；详见 [验证记录](VALIDATION.md)。

MCP resources 由官方插件提供，需要配置相应 MCP 服务；不能把“随内核提供”理解为所有第三方服务均已验收。

本版不启用 Browser Use、Computer Use、Auto review 或远程命令桥；不升级 Electron/Node/pnpm，不迁移到官方桌面壳，不宣称所有第三方插件已验证。官方 Messages API 为新默认协议，既有自定义端点/插件须单独验证。

升级前保留独立会话/设置备份。即使 Session 仍称 V3，新事件也可能不被旧内核识别；回退必须使用独立升级前资料，不能用旧程序直接恢复升级后的活动资料。未签名、另一台 Windows 和至少 24 小时老化仍未验收，自动安装不启用。

Office 恢复交互/Portable 性能调整至 V1.1.14，最终功能集老化调整至 V1.1.15；V1.2.0 继续以两台 Windows 的完整验收为门槛。

# DSH Desktop V1.1.9

Office 安全检查与真实交付收据。保留 Harness `0.1.2-rc.1`、现有 Office 中心和官方聊天/产物入口；Stable 保持 V1.1.0。

## 本版变化

- Word、Excel、PPT 共用有界 ZIP 和命名空间感知 XML 检查，拒绝异常目录、条目重叠、加密、宏、外部关系、活动内容和敏感路径。Word 修改前也进行严格检查。
- PPT 内嵌图表工作簿执行 Excel 严格检查，不能用 XML 编码或命名空间别名绕过风险公式限制。
- 创建和受支持修改的结果增加真实文件大小、相对路径、SHA-256、是否覆盖及备份摘要。模型被明确要求区分结构安全检查与未执行的排版验收。
- 发布新产物前完成检查；覆盖保留回退副本，避免先删除旧文件再替换。交付时重新读取磁盘文件，检测到变化就停止报告旧结果。
- PDF 原生烟测升级为三页中文、嵌入字体、分页和逐页截图。没有新增任意 PDF 编辑能力。
- 固定 XML 解析器 `@xmldom/xmldom@0.9.12`，同步运行资源、锁文件和第三方许可证清单。

## 兼容与限制

- 严格模式只支持受限 OOXML；外部链接、宏、活动域及不支持的编码/结构会被拒绝，不会自动删除这些内容。需要在 Office 中移除相应内容后另存。
- 收据是校验当时的文件快照，不是持续监控、持久化恢复界面或恶意软件安全认证；不保证任意 Office 客户端的像素级排版一致。文件写入在本机 NTFS 验证，不承诺全部网络共享或非 NTFS 文件系统。
- 恢复卡片、Portable 冷启动优化和 Harness alpha.1 的 Session v2 迁移均留到后续独立切片；本轮只迭代一个版本。
- 安装器仍未签名，自动安装保持禁用；不晋升 Stable。

## 验收与发布

已于 2026-09-07 完成本机覆盖安装和 GitHub Pre-release 发布：源码回归 545/545、最终相关门禁 32/32，生产依赖审计、真实 DeepSeek 调用和安装态专项通过。36 个会话/配置文件及 2 个加密凭据文件保持不变；公开下载四项资产的大小与 SHA-256 全部匹配，校验清单 3/3 通过。Stable 仍为 V1.1.0。

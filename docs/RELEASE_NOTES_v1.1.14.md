## 本版范围

- 采用官方 Office 转换与侧栏预览、文件改动卡片、插件管理及会话可靠性改进；具体替换边界见 [能力对比](HARNESS_UPSTREAM_v0.1.6-alpha.2.md)。
- 适配公开 Session binding 和显式主会话导航；文件授权后复核会话代次，保留切换、卸载、异步过期请求保护。
- 跟随官方插件解析变化，三个固定桌面插件使用软件资料目录的原生后备位置；不篡改官方解析规则、用户 Profile 或删除旧版桥接副本。
- Windows x64 固定引擎 `@deepseek-ai/libreoffice-kit-win32-x64@0.0.1`，保留完整源码补丁和许可证。用户已接受约 325.1 MiB 的解压体积；引擎 npm 压缩包为 116,839,874 字节，最终安装包增量尚未实测。
- 校验固定原生引擎及全部清单文件；缺包、摘要变化或混入其他平台引擎时拒绝打包验收，不静默退回 WASM。
- 继续保留软件优先的加密 Key、代理、Office/Wiki 校验及备份、Git Review 和 Windows 宿主保护。官方临时改动卡片不等于持久化 Git Review；插件全 Profile 变更及卸载仍待实际验证。

## 当前已验证

- 完整源码 621/621，通过真实运行库审计及 2,048 项原生引擎摘要核验；Office 新增 ZIP64 风险使用精确 `fflate@0.8.3` 修复，并保留旧版失败对照。

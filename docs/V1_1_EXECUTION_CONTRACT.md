# V1.1 执行与验收约定

2026-08-31 用户批准从 V1.0.1 连续迭代至 V1.1。远程 Codex 工作节点不属于本任务，不进入产品路线。

## 交互契约

- Windows 桌面工作台，沿用系统字体、中性内容底色、现有语义色；不重建品牌。
- 主流程：当前工作区 → 输入问题与资料 → 执行/审批 → 查看变更和交付物 → 继续。
- 文件入口支持拖放和点击；源文件不修改，外部资料受控导入，未发送不宣称 AI 已读取。
- 状态明确：未连接、等待、导入中、已附加、执行中、待确认、完成、失败、取消。
- 键盘操作、可见焦点、Escape、关闭后焦点恢复；紧凑窗口和高缩放不遮挡主操作。
- 主进程校验所有路径、会话和 IPC；不得为便利关闭沙箱或把终端权限提供给网络页面。

## 每版门禁

1. 独立版本变更与回归测试；类型、边界、错误和恢复分支均覆盖。
2. 真实渲染与关键操作检查，区分模拟、源码、解包、已安装和真实模型证据。
3. 打包前安全/凭据检查；覆盖前保留可回滚安装包与不含凭据的语义快照。
4. 覆盖后回读版本、关键功能与既有数据；失败不进入下一发布。
5. GitHub 仅 Pre-release；资产上传、摘要和匿名回下载一致后才标为已发布。
6. Stable V0.5.4 不变。证书、外部服务或用户选择不足时如实报告，不伪造签名或放宽门禁。

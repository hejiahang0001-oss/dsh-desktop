# 软件 Key 与 Windows 加密存储

V1.0.2 候选把软件凭据托管到 Windows 当前账户的 Electron safeStorage / DPAPI。不是端到端加密，也不防御已控制当前 Windows 账户或 Harness 进程的恶意代码。

## 使用和迁移

- 继续在软件模型设置中保存 Key；Windows 环境变量不会覆盖软件设置。
- 存储位置为应用数据下 `harness/.credentials.dpapi.json`；备用文件也只保存密文。
- 首次启动读取已有 `.credentials.yaml`，按上游版本化格式校验，原子保存密文并解密回读。加密组件在真实 Harness 中确认激活、旧明文组件确认停用之后，才移除未发生变化的旧凭据文件。
- 加密失败、磁盘失败、组件未就绪或旧凭据发生并发编辑时停止迁移并提示，不用空值覆盖旧 Key。
- 模型设置页面仅写入 Key、读取配置状态。Key 通过桌面父子进程专用通道交给 Harness 凭据接口，不放入启动参数、进程环境、终端、Office 或普通诊断/备份。
- 任意第三方插件与 Harness 运行在同一进程时仍属于受信代码，不能把 DPAPI 描述为插件沙箱。

## 覆盖、便携和回退

- 同一 Windows 账户覆盖新版保留凭据；复制程序到另一台电脑不携带可直接使用的 Key。
- 不可解密时拒绝覆盖原密文。请回原电脑/账户使用，或保留原密文后重新配置；程序不会自动清空它。
- V1.0.1 及以前不能读取新的密文格式。回退程序不删除密文，但旧版需要重新填写 Key；不自动生成明文回退副本。返回新版前需要处理旧版新写出的凭据冲突，不能假定双版本并行写入安全。
- 未签名状态保持明确，自动下载安装仍禁用；SHA-256 完整性校验不能代替代码签名。

## 文件入口边界

Excel/Word/PDF 可从文件选择器或本机文件拖放进入输入；外部资料复制到工作区，工作区内资料直接引用。发送才会交由模型处理，附加成功不等于读取成功。PDF 导入与本地预览不承诺扫描件 OCR；`.xls`、`.doc` 和宏文档目前提示转换格式后重试。
